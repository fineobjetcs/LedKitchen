# LedKitchen: ESP32 DevKit + Home Assistant

Конфигурация управляет тремя диммируемыми одноцветными зонами через аппаратный
PWM ESP32 и одним обычным выходом HNY. Все четыре светильника публикуются в Home
Assistant через нативный ESPHome API. PWM-зоны включаются, выключаются и меняют
яркость плавно за 3 секунды.

## Подключение

| Название | Назначение на скриншоте | GPIO ESP32 |
|---|---:|---:|
| Диван | PWM 0 | GPIO12 |
| Стол | PWM 1 | GPIO13 |
| Кухня | PWM 2 | GPIO14 |
| HNY | обычный выход | GPIO27 |

PWM-пины следует подключать **к управляющим входам MOSFET-драйверов**, а не
непосредственно к мощной светодиодной ленте. Земля ESP32 и блока питания лент
должна быть общей. GPIO27 — также выход на драйвер светодиода, но без
регулировки яркости. Кнопки в этой конфигурации нет: управление выполняется из
Home Assistant.

> GPIO12 — strapping-пин ESP32. Драйвер не должен подтягивать его вверх во время
> старта, иначе плата может не загрузиться. Если модуль драйвера это делает,
> перенесите канал Divan на безопасный PWM-пин (например GPIO25) и измените
> `pin` в YAML.

## Установка ESPHome

1. Скопируйте пример секретов и заполните значения:
   ```bash
   cp esphome/secrets.yaml.example esphome/secrets.yaml
   openssl rand -base64 32
   ```
2. Проверьте и впервые прошейте плату по USB:
   ```bash
   esphome config esphome/led-kitchen.yaml
   esphome run esphome/led-kitchen.yaml
   ```
3. В Home Assistant откройте **Settings → Devices & services → ESPHome** и
   добавьте `led-kitchen.local`. Три регулятора яркости и выключатель HNY
   появятся автоматически.

Значение `fade_time` в начале `esphome/led-kitchen.yaml` позволяет поменять
длительность перехода сразу для всех PWM-каналов. Канал HNY может только
включаться и выключаться, поэтому плавный переход к нему не применяется.

## Необязательный пакет Home Assistant

Файл `home-assistant/packages/led_kitchen.yaml` добавляет группу всех зон и два
скрипта для плавного общего включения/выключения. Скопируйте его в каталог
`packages` конфигурации HA и включите пакеты в `configuration.yaml`:

```yaml
homeassistant:
  packages: !include_dir_named packages
```

После перезапуска HA будут доступны `script.led_kitchen_on` и
`script.led_kitchen_off`. Если Home Assistant назначил сущностям другие ID,
замените четыре `entity_id` в пакете на фактические значения из интерфейса HA.
